# Maintainers

This document lists the current maintainers of the **oms-reference-customizations** project.

Maintainers are responsible for reviewing and merging pull requests, triaging issues, and guiding the direction of the project. At least one maintainer approval (LGTM) is required before a pull request can be merged.
